# Terraform AWS Infrastructure

Infrastructure as Code (IaC) project built using Terraform to provision and manage AWS resources efficiently.

---

## 📌 Overview

This repository contains Terraform configurations for automating cloud infrastructure deployment on Amazon Web Services (AWS).

The project demonstrates:
- Infrastructure as Code (IaC)
- AWS resource provisioning
- Terraform workflows
- Reusable and modular infrastructure
- Cloud automation best practices

Terraform enables infrastructure to be defined, versioned, and managed using code. :contentReference[oaicite:0]{index=0}

---

## 🛠️ Tech Stack

- Terraform
- AWS (Amazon Web Services)
- HCL (HashiCorp Configuration Language)
